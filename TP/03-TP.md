## 🚀 **TP 1 : Introduction à Symfony 6.4 et Configuration d'un Projet**

### Objectifs :
- Installer Symfony 6.4.
- Créer un projet Symfony.
- Comprendre la structure du projet.
- Découvrir le modèle MVC.

### Étapes à suivre :

### 1. **Prérequis**

- Assurez-vous d’avoir PHP 8.1 ou plus installé sur votre machine.
- Installez Composer, le gestionnaire de dépendances PHP.

### 2. **Installer Symfony CLI**

Exécutez la commande suivante pour installer Symfony CLI (si ce n'est pas déjà fait) :
```bash
composer global require symfony/cli
```

### 3. **Créer un Nouveau Projet Symfony**

Créez un projet Symfony avec la commande suivante :
```bash
symfony new myproject --version="6.4.*" --webapp
```
Cela créera un projet Symfony dans un dossier nommé `myproject` et configurera un environnement web de base.

### 4. **Explorer la Structure du Projet**

Voici à quoi ressemble la structure d'un projet Symfony par défaut :
```
myproject/
│
├── config/                  # Configuration de l'application
├── src/                     # Code source : contrôleurs, entités
├── templates/               # Templates Twig (Vue)
├── var/                     # Cache et logs
└── public/                  # Fichiers accessibles au public (CSS, JS, images)
```

### 5. **Créer un Contrôleur et une Vue**

**Contrôleur :**
Créez un fichier `src/Controller/HelloController.php` avec ce contenu :
```php
namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class HelloController extends AbstractController
{
    #[Route('/hello', name: 'app_hello')]
    public function hello(): Response
    {
        return $this->render('hello/index.html.twig');
    }
}
```

**Vue :**
Créez un fichier `templates/hello/index.html.twig` avec ce contenu :
```twig
<!DOCTYPE html>
<html>
    <body>
        <h1>Hello, Symfony 6.4!</h1>
    </body>
</html>
```

### 6. **Lancer le Serveur de Développement**

Lancez le serveur de développement intégré de Symfony avec cette commande :
```bash
symfony server:start
```
Accédez à `http://localhost:8000/hello` pour voir votre page.

---

### **Solution TP 1 : Résumé**

- Vous avez installé Symfony 6.4 et créé un nouveau projet avec `symfony new`.
- Vous avez exploré la structure du projet Symfony.
- Vous avez créé un contrôleur et une vue simple.

## 🚀 **TP 2 : Utilisation de Doctrine et Gestion des Migrations**

### Objectifs :
- Créer une entité et gérer la base de données avec Doctrine.
- Appliquer des migrations à la base de données.
- Créer un contrôleur pour afficher les données d'une entité.

### Étapes à suivre :

### 1. **Création de l'Entité Article**

Créez une entité `Article` avec les commandes suivantes :

Exécutez la commande :
```bash
php bin/console make:entity
```
Lorsque Symfony vous demande le nom de l'entité, entrez `Article`. Ajoutez des propriétés comme `title` (type `string`) et `content` (type `text`).

La classe `Article` ressemblera à ceci :
```php
namespace App\Entity;

use Doctrine\ORM\Mapping as ORM;

/**
 * @ORM\Entity(repositoryClass="App\Repository\ArticleRepository")
 */
class Article
{
    /**
     * @ORM\Id()
     * @ORM\GeneratedValue()
     * @ORM\Column(type="integer")
     */
    private $id;

    /**
     * @ORM\Column(type="string", length=255)
     */
    private $title;

    /**
     * @ORM\Column(type="text")
     */
    private $content;

    // Getters et setters...
}
```

### 2. **Générer la Migration**

Exécutez la commande suivante pour générer une migration pour votre entité :
```bash
php bin/console make:migration
```

### 3. **Appliquer la Migration**

Pour appliquer la migration à la base de données, exécutez :
```bash
php bin/console doctrine:migrations:migrate
```

### 4. **Créer un Contrôleur pour Afficher les Articles**

Créez un contrôleur `ArticleController.php` pour afficher les articles.

```php
namespace App\Controller;

use App\Repository\ArticleRepository;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Annotation\Route;

class ArticleController extends AbstractController
{
    #[Route('/articles', name: 'app_articles')]
    public function index(ArticleRepository $articleRepository): Response
    {
        $articles = $articleRepository->findAll();
        return $this->render('article/index.html.twig', [
            'articles' => $articles,
        ]);
    }
}
```

### 5. **Afficher les Articles dans la Vue**

Créez une vue `article/index.html.twig` pour afficher la liste des articles.

```twig
<!DOCTYPE html>
<html>
    <body>
        <h1>Liste des Articles</h1>
        <ul>
            {% for article in articles %}
                <li>{{ article.title }} : {{ article.content }}</li>
            {% endfor %}
        </ul>
    </body>
</html>
```

### 6. **Test de l’Affichage des Articles**

Lancez le serveur de développement avec la commande :
```bash
symfony server:start
```
Accédez à `http://localhost:8000/articles` pour voir la liste des articles.

- Vous avez généré une migration et appliqué les modifications à la base de données.
- Vous avez créé un contrôleur pour afficher les articles.
